# Card art

Drop finished card images here and they are picked up automatically on the next build
(no code change needed). Spec: [docs/art-spec.md](../../../../../docs/art-spec.md).

- Name files after the role id: `role-werewolf.png`, `role-seer.webp`, `role-wolf-cub.png`, …
  (One Night roles use the same names: `role-robber.png`, `role-troublemaker.png`, …)
- `card-back.png` replaces the striped card back.
- PNG, WebP, JPG or SVG; 5:7 portrait, ideally 1500×2100 px.
